What does CPU double buffering solve?

Two independent slots let the CPU thread alternate between buffers A and B: while the GPU uses A, the CPU prepares B. This hides host-side preparation time.

What do multiple CUDA streams solve?

Each slot has its own stream and execution context. With pinned memory and asynchronous APIs, H2D copies can overlap Tensor Core computation in another stream.

Ownership boundaries when combined

CPU finishes a slot → an event releases H2D; H2D completes → inference reads; compute completes → the slot returns to CPU. Independent buffers, contexts, and streams are required for safe concurrency.
