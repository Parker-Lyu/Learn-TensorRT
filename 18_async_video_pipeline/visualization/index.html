CPU 双缓冲解决什么？

两个独立 slot 让 CPU 线程交替写入 buffer A/B：GPU 使用 A 时，CPU 可准备 B。它隐藏的是主机端准备时间。

多 CUDA Stream 解决什么？

每个 slot 有自己的 stream 和 execution context。借助 pinned memory 与异步 API，H2D 拷贝可以和另一 stream 的 Tensor Core 计算并行。

组合时的所有权边界

CPU 写完 slot → 事件通知 H2D；H2D 完成 → 推理读取；计算完成 → slot 归还 CPU。没有独立 buffer、context、stream 就不能安全并发。
